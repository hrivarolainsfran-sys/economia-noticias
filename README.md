# Economía en las Noticias

Noticias económicas de Paraguay explicadas con diagramas de Economía IB. Sitio: https://hrivarolainsfran-sys.github.io/economia-noticias/

Secciones: noticias con su análisis, resumen semanal, indicadores con su evolución, Paraguay frente a la región, diagramas interactivos, calculadoras y diarios. Se puede instalar como app en el celular.

- `index.html`: la página.
- `datos.json`: noticias, indicadores, historial, región y semanas. Se actualiza todos los días.
- `sw.js`, `manifest.webmanifest`, `iconos/`: la app instalable.
- `ACTUALIZAR.md`: formato y reglas para actualizar los datos.
