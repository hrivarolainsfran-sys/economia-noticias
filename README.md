# Economía en las Noticias

Noticias económicas de Paraguay explicadas con diagramas de Economía IB. Cada noticia resume lo que pasó, muestra las cifras clave, explica la cadena causal, define los conceptos y enlaza al diario original.

- `index.html`: la página.
- `datos.json`: las noticias, que se actualizan todos los días.
- `ACTUALIZAR.md`: formato y reglas para agregar noticias.
